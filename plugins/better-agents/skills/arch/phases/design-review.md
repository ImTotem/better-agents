# `design-review` 단계

1. architecture.md 전체를 다시 읽고 확인한다: 결정끼리 모순이 없는지, 현재 라운드의 모든 `high` 드라이버가 결정에 연결됐는지, 드라이버 분석이 최신인지, 부분·미충족 드라이버를 어떻게 처리할지.
2. 구조도, 핵심 결정, 부분·미충족 드라이버를 요약해 보여 주고 사용자 검토를 받는다.
3. 반복이 더 필요하면 `GA 되돌리기`를 요청한다(반복이 하나 추가되고 `iterating`으로 돌아간다). 새 반복에서 다룰 드라이버는 `ga_update`로 `"priority":"high"`와 새 반복 번호(`ga status`의 현재 반복)로 바꾸고 `phases/iterating.md`를 따른다.
4. SKILL.md 1절의 검증과 승인 절차 후 `GA 승인 설계`를 요청한다. 승인 조건: 현재 라운드의 모든 `high` 드라이버가 어떤 결정에 연결됨.
